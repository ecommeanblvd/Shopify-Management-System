# Quản lí đơn P2.1 — gộp hẳn trang chi tiết (fold pack/MMP) + redirect — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps dùng checkbox (`- [ ]`).
> Slice cuối của spec `docs/superpowers/specs/2026-07-04-quan-ly-don-merge-design.md` §4 (P2 row: "trỏ worklist + fulfillment detail → trang hợp nhất").

**Goal:** Fold 3 panel thao tác (`OrderDetailPanel`, `MmpPushBadge`, `PackPanel`) vào trang chi tiết hợp nhất `/f/lifecycle/[orderId]`, rồi redirect `/f/fulfillment/[orderId]` + trỏ worklist về đó — 1 trang chi tiết duy nhất, KHÔNG mất chức năng đóng gói/ship/MMP.

**Architecture:** Mở rộng `getOrderDossier` (thêm `picked`/`mmp`/`fulfillmentStatus`) → trang hợp nhất render thêm 3 panel với RBAC → redirect + wire. Đọc/ghi qua action sẵn có, KHÔNG migration.

**Tech Stack:** Next.js App Router (RSC), Drizzle, React 19, Vitest.

## Global Constraints

- KHÔNG migration; tái dùng component + action + query sẵn có.
- Redirect fulfillment detail CHỈ ở Task 3 — SAU khi Task 2 đã fold đủ 3 panel (không mất chức năng, đúng bài học C1 của P2).
- RBAC: `canManage = hasPermission(role, 'manage_fulfillment')`, `canCheckPacked = hasPermission(role, 'check_packed')` — y hệt trang fulfillment cũ.
- `getOrderDossier` server-only; chỉ dùng ở RSC.

### Task 1: Mở rộng `getOrderDossier` — thêm `picked` / `mmp` / `fulfillmentStatus`

**Files:** Modify `features/orders/dossier.ts`

**Interfaces:**
- Consumes thêm: `pickedUnassignedLines(orderId)` từ `@/features/packing/queries` (dossier đã import `listPacksForOrder` cùng file). `getMmpPushInfo` đã import sẵn (dùng cho signals). `getFulfillmentDetail` đã gọi (có `.fulfillment.status`).
- Produces: `OrderDossier` thêm field `picked`, `mmp`, `fulfillmentStatus`.

- [ ] **Step 1: Sửa dossier**

1. Thêm import `pickedUnassignedLines` vào dòng import từ `@/features/packing/queries`:
```ts
import { listPacksForOrder, pickedUnassignedLines } from '@/features/packing/queries';
```
2. Thêm type + field vào `OrderDossier`:
```ts
type Picked = Awaited<ReturnType<typeof pickedUnassignedLines>>;
type MmpInfo = Awaited<ReturnType<typeof getMmpPushInfo>>;
```
Trong `interface OrderDossier`, thêm:
```ts
  picked: Picked;
  mmp: MmpInfo;
  fulfillmentStatus: string | null;
```
3. Thêm `pickedUnassignedLines(orderId)` vào `Promise.all` (cạnh các query song song). `mmp` (biến `getMmpPushInfo` đã có trong Promise.all) và `detail` (getFulfillmentDetail) đã sẵn.
4. Trả thêm trong object return:
```ts
    picked,
    mmp,
    fulfillmentStatus: detail?.fulfillment?.status ?? null,
```
(đặt `picked` vào Promise.all + destructure; `detail`/`mmp` đã có.)

### Task 2: Trang hợp nhất render 3 panel thao tác + RBAC

**Files:** Modify `app/(dashboard)/f/lifecycle/[orderId]/page.tsx`

**Interfaces:**
- Consumes: `OrderDetailPanel` ({status, lines, canManage}), `MmpPushBadge` ({info, orderId, canManage}), `PackPanel` (shape map như dưới) từ `@/components/fulfillment/...`; `hasPermission` (đã import qua rbac); dossier fields mới (T1).

- [ ] **Step 1: Thêm panel vào trang**

Trong `app/(dashboard)/f/lifecycle/[orderId]/page.tsx`:
1. Import:
```ts
import { OrderDetailPanel } from '@/components/fulfillment/OrderDetailPanel';
import { MmpPushBadge } from '@/components/fulfillment/MmpPushBadge';
import { PackPanel } from '@/components/fulfillment/PackPanel';
```
2. Sau khi có `role` + `dossier`, tính quyền:
```ts
  const canManage = hasPermission(role, 'manage_fulfillment');
  const canCheckPacked = hasPermission(role, 'check_packed');
```
3. Trong JSX, THÊM (đặt trong khối "panel bổ trợ" — sau timeline/hành trình, cạnh `AddressVerifyCard`/`LarkDetailCard` đã có). Thứ tự đề xuất: OrderDetailPanel → MmpPushBadge → AddressVerifyCard (đã có) → PackPanel → LarkDetailCard (đã có):
```tsx
      <OrderDetailPanel status={dossier.fulfillmentStatus ?? '—'} lines={dossier.lines} canManage={canManage} />
      <MmpPushBadge info={dossier.mmp} orderId={orderId} canManage={canManage} />
      {/* AddressVerifyCard đã có ở đây */}
      <PackPanel
        orderId={orderId}
        picked={dossier.picked}
        packs={dossier.packs.map((p) => ({
          id: p.id, code: p.code, carrierKey: p.carrierKey, trackingNumber: p.trackingNumber,
          checkPackedAt: p.checkPackedAt as Date | null, actualWeightKg: p.actualWeightKg,
          lines: p.lines.map((l) => ({ id: l.id, sku: l.sku, qty: l.qty, status: l.status, productTitle: l.productTitle })),
          shopifyPushStatus: p.shopifyPushStatus, shopifyPushError: p.shopifyPushError,
          deliveryStatus: p.deliveryStatus, deliveredAt: p.deliveredAt, trackDetail: p.trackDetail, lastTrackedAt: p.lastTrackedAt,
        }))}
        canManage={canManage}
        canCheckPacked={canCheckPacked}
      />
```
(Map `packs` giống hệt trang fulfillment cũ để khớp prop `PackPanel`.)
